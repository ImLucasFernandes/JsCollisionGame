You've Already Lost The Game

Welcome to the game You've Already Lost. Avoid the enemy moving squares, if you collide with them you lose. If you run out of time, you lose. Increase the timer by hitting the yellow Time Ups. hitting borders will shoot you in the opposite direction, try not to go mad!

Controls are AWSD respectively, click anywhere in the game windo with the mouse to begin, the square will move in the associated key direction constantly.

You are currently the white square with the animated border. If you wish to change the color, input the first lowercase letter of the desired color. Color options include: orange, turqoise and green:
